Below is a **ready‑to‑use “Home” page** with a clean layout, responsive design, and a touch of modern styling.  
Save the two snippets into **two separate files**:

| File | Purpose | How to use |
|------|---------|------------|
| `index.html` | The HTML structure | Open in a browser |
| `style.css` | The visual styling | Link to it from the `<head>` of the HTML |

---

### How it works

1. **Open** the two files in the same folder (`index.html` + `style.css`).
2. **Open** `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
3. **Scroll** to see the sections: Hero → Services → About → Contact.
4. **Resize** the browser window to see the responsive grid in the Services section.

Feel free to replace the placeholder text, images, and colors with your own content. Happy coding!
